# Как писать сюжетные разговоры

Разговоры лежат в `data/dialogues/*.dlg` — обычные текстовые файлы, читаются как пьеса. Править можно в любом редакторе. Игра показывает их на отдельном экране: портрет того, кто говорит, история реплик, кнопка «Дальше» или варианты ответа.

Разговор начинается утром, раньше сцен в чате (или вечером, если указано `at: evening`), и проигрывается один раз за игру. Если в одно утро подходят несколько сцен, берётся первая по порядку: файлы читаются по алфавиту, сцены — сверху вниз.

## Пример

```
== alex_reports
when: chapter 1, day 3-8, here alex, not flag automated_report

- Алексей заходит без стука, ноутбук под мышкой.
  en: Alex walks in without knocking, laptop under one arm.
alex [excited]: Давай я сделаю, чтобы отчёт сам собирался.
  en: Let me make the report build itself.
{if here vika} vika [annoyed]: Отчёт вообще-то делаю я.
  en: I'm the one who does that report, actually.
* Делай. Идея отличная. -> himself
  en: Go ahead. Great idea.
* Давай не сейчас. -> later
  en: Not now.

-- himself
alex [happy]: К пятнице будет.
  en: Done by Friday.
> give automate_report alex
> mood alex +1
-> end

-- later
alex: Как скажешь.
  en: Your call.
-> end
```

## Строки

| Строка | Что это |
|---|---|
| `== id` | Начало сцены. id — латиницей, уникальный |
| `when: …` | Когда сцена может начаться (условия ниже, через запятую — все должны выполниться) |
| `at: evening` | Сцена идёт вечером, в конце дня перед итогами. Без этой строки — утром |
| `кто [эмоция]: текст` | Реплика. Эмоцию можно не указывать |
| `you: текст` | Реплика игрока без выбора |
| `- текст` | Описание, без говорящего |
| `  en: текст` | Английский перевод строки над ним. Обязателен для каждой реплики и варианта |
| `* текст -> метка` | Вариант ответа. Подряд идущие `*` — один выбор |
| `-- метка` | Начало ветки, куда ведут варианты и переходы |
| `-> метка` | Перейти к ветке; `-> end` — закончить разговор |
| `> эффект` | Что меняется в игре (ниже) |
| `{if условие} …` | Перед любой строкой: показать её, только если условие выполнено |
| `# текст` | Комментарий, игра его не читает |

Если ветка закончилась без `->`, разговор заканчивается: следующая ветка не начинается сама.

## Кто говорит

`alex`, `vika`, `dima`, `gena`, `taras`, `boss` (Ирина Викторовна), `marina`, `boris`, `stas`, `olga`, `you` (игрок).

## Эмоции

`neutral` спокойствие, `happy` радость, `excited` воодушевление, `annoyed` раздражение, `angry` злость, `tired` усталость, `sad` грусть, `worried` тревога, `embarrassed` смущение, `sarcastic` сарказм.

Эмоция видна как цвет кольца вокруг портрета и подпись под ним. Когда появятся настоящие портреты, у каждого персонажа будет картинка на каждую эмоцию.

## Условия

| Условие | Выполнено, если |
|---|---|
| `chapter 1` или `chapter 2-3` | идёт эта глава |
| `day 3-8` | день главы в этих пределах (с 1-го) |
| `here alex` | человек в команде и не на больничном |
| `flag x` | в игре стоит отметка `x` |
| `busy dima < 4` | у человека в работе меньше 4 задач (можно `>=`, `>`, `<=`) |
| `not …` | наоборот: `not flag x`, `not here vika` |

**Память о выборах.** Каждый выбранный ответ сам ставит отметку `сцена:метка`. Например, после ответа `-> to_vika` в сцене `alex_reports` стоит `alex_reports:to_vika`, и любая следующая сцена может спросить `{if flag alex_reports:to_vika}`.

## Эффекты

| Эффект | Что делает |
|---|---|
| `> flag x` / `> unflag x` | поставить / снять отметку |
| `> days x 3` | отметка `x`, которая действует 3 дня (для правил вроде «первые дни после…») |
| `> mood alex +1` | настроение (от −5 до 5) |
| `> trust alex -1` | доверие к вам |
| `> energy alex -2` | силы |
| `> style I 0.5` | сдвиг стиля руководства игрока: P результат, A порядок, E перемены, I люди |
| `> boss +1` | вес у Ирины Викторовны |
| `> give automate_report alex` | отдать задачу или улучшение человеку прямо в разговоре, без возражений |
| `> give automate_report alex helper vika` | то же, с напарником |
| `> grab dima 5` | человек сам набрал себе работы: из очереди (сначала мелкие), из утренних задач, а если мало, то новые, пока в работе не станет 5 |
| `> drop dima 2` | оставить ему 2 задачи, где он дальше всех продвинулся, остальные вернуть в очередь |
| `> reveal alex skill.support` | игрок узнаёт навык (`skill.pipelines` / `infra` / `portal` / `support`) или мотив (`drive`) |

## Проверка

Сломанная строка, переход в несуществующую ветку, незнакомый персонаж или эмоция, реплика без `en:` — всё это ловит проверка сценариев (её запускаю я перед каждым коммитом).

### Глава 4: условия и эффекты для отголосков

| Запись | Что значит |
|---|---|
| `laid_off gena` | в главе 3 по приказу сократили именно Гену |
| `incident` | сейчас есть незакрытая авария |
| `> task old_jenkins_down` | положить карточку в очередь (как будто её прислали) |
| `> shrink bus_factor 0.5` | задача оказалась вдвое меньше: и та, что уже есть, и та, что ещё придёт; `shrink incident 0.5` — все открытые аварии |
