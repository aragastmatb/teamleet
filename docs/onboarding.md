# Обучение через окружение (бесконечный режим)

Решение 01.11.2026. Подсказки Марины в чате бесконечного режима заменены подсветкой. В первый месяц (если подсказки включены в настройках) механика показывается в тот момент, когда впервые появилась в игре: экран затемняется, нужное место обведено, рядом пузырёк Марины с аватаркой.

- **Обязательные** (затемнение пропускает клики только туда, куда она показывает): открыть первую карточку, выбрать человека, ответить на возражение, открыть первое письмо.
- **Остальное** закрывается «Понятно» или кликом мимо.
- Если показать не на что (другая раскладка, например телефон), будет просто пузырёк с «Понятно»: обучение никогда не запирает игру.
- Каждый момент показывается один раз за игру (флаги `coach_*` в сохранении).

| Момент | Что подсвечено | Обязательно |
|---|---|---|
| первое утро | карточка во входящих | да |
| окно задачи | люди, кому отдать | да |
| возражение | варианты ответа | да |
| после первой раздачи | «За работу» | нет |
| середина дня | команда и полоски | нет |
| первое письмо | контакт (на телефоне вкладка «Чат») | да |
| открыта переписка с письмом | варианты ответа, про молчание | нет |
| очки кончились | кружки наверху | нет |
| конец середины дня | «Закончить день» | нет |
| вечер | «Следующий день» | нет |
| стендап | окно стендапа | нет |
| первая просрочка | просроченная карточка | нет |
| пятничный разбор | вопрос Ирины | нет |
| пришли резюме | «Кандидаты» | нет |
| хватает на улучшение | «Улучшения» | нет |
| кто-то без задач (с 6-го дня) | «Клиенты» | нет |
| конец месяца | защита бюджета | нет |

Код: `_coach_steps()` в main.gd — список, порядок и условия; тексты `coach.*` в locale.gd. Сюжетный режим пока на старых подсказках в чате.
